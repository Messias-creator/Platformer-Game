“Your first ten games will suck — so get them out of the way fast.” — Jesse Schell

Este projeto é o primeiro de uma série de 10 jogos que pretendo desenvolver.

O objetivo não é criar jogos perfeitos, mas aprender fazendo. Cada projeto será uma oportunidade para experimentar novas ideias, aprender com os erros e, principalmente, ganhar experiência no processo de desenvolvimento.

Mais do que aprender ferramentas e técnicas, essa série tem um objetivo pessoal: perder o medo de começar e, principalmente, terminar projetos.

A ideia é deixar para trás o ciclo de começar algo, buscar a perfeição, aumentar demais o escopo e nunca chegar ao fim.

10 jogos. 10 oportunidades de aprender. O mais importante é terminar.
